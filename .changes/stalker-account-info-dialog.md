Stalker portals now have an Account info dialog — subscription status,
tariff plan, expiry date with a days-left counter, login, and portal
details. Open it from the header playlist menu, the dashboard source card,
or the command palette, same as for Xtream. If the portal is unreachable,
the data saved when the portal was added is shown instead.
