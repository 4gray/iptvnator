Playback keyboard shortcuts now work with the default player setup: Space/K
(play/pause), F (fullscreen), ←/→ (seek 5s in VOD), ↑/↓ (volume), and M (mute)
act on the built-in HTML5, Video.js, and ArtPlayer players without turning on
shared player controls — matching what the in-app shortcut list already
promised.
