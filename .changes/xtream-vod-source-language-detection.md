The movie sources popover now recognizes more language tags: prefixes with
Unicode pipes, brackets or dashes ("EN │ …", "[EN] …", "EN - …"), Cyrillic
tags ("РУС | …") and MULTI. It also reads the language off category names
("EN | Netflix"), and a tag welded to a title ("EN|Movie") no longer hides
that copy from the other playlists' copies of the same movie.
