type: feature
area: epg
highlight: Local XMLTV files as EPG sources
---

EPG sources no longer have to be URLs: point Settings → EPG or a playlist's EPG list at an XMLTV file on your computer, as an absolute path (`/home/you/guide.xml.gz`, `C:\epg\guide.xml`), a `file://` link, or by picking it with the new folder button. Plain `.xml` and gzip `.xml.gz` both work, and the settings page now spells out the accepted formats with examples.
