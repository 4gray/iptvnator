# @iptvnator/pipes

Shared UI utilities: date formatting (`formatWithIntl`,
`normalizeDateLocale`), `SafePipe`, and `injectTranslationTick()`, the
language signal that every `computed` calling `TranslateService.instant`
reads (see "Translated Text" in the
[UI guidelines](../../../docs/architecture/iptvnator-ui-guidelines.md)).

This library was generated with [Nx](https://nx.dev).

## Running unit tests

Run `nx test @iptvnator/pipes` to execute the unit tests.
